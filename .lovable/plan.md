# Refresh the Six Standard ATS Challenge Covers

Replace the artwork for these American Truck Simulator challenges only:

- ATS - Bronze Challenge
- ATS - Silver Challenge - Uncommon Rarity
- ATS - Gold Challenge - Uncommon Rarity
- ATS - Platinum Challenge - Legendary Rarity
- ATS - Podium Challenge - Epic Rarity
- ATS - Champion Challenge - Legendary Rarity

## Visual direction

- Create one cohesive widescreen cover for each tier using cinematic American trucking scenes inspired by the existing ATS community identity.
- Give every tier a distinct, recognizable treatment: bronze, silver, gold, platinum, podium, and champion.
- Keep trucks, highways, freight, weather, scenery, and lighting as the visual focus.
- Include only the exact challenge title on each finished image—no rarity labels, logos, stats, badges, slogans, or other copy beyond words already present in that title.
- Compose titles with strong contrast and safe margins so they remain readable in both the challenge card crop and challenge detail view.

## Delivery

- Generate clean background art first, then add the exact titles during image composition for reliable spelling and typography.
- Store the six finished images with the app's managed media.
- Update only the six corresponding ATS challenge cover-image records; leave ATS Skills and CDL challenge artwork unchanged.
- Verify all six cards on the ATS game page and one challenge detail page at desktop and mobile sizes, checking crop, title legibility, and image loading.

## Technical details

- Use a consistent wide aspect ratio matching the existing challenge-card and detail-page image treatments.
- Preserve all challenge names, difficulty levels, points, tasks, enrollments, merit mappings, and availability settings.
- Do not change the ATS community banner, other games, marketing, dispatch, approved posts, queues, or the kill switch.
